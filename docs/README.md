# 景気玉 設計書

## 概要
景気玉は、景気によって当選確率が変動するお年玉増額ルーレットです。<br/>
経済指標6つのうち「○」の数だけ当たり枠が増え、ハズレでもお年玉は据え置き (減ることはない) です。<br/>
お年玉を渡す側が、画面に表示された上乗せ額を基準額に足して渡します。

## 前提
- スマートフォン (縦画面) での表示を前提とする。
- Cloudflare Workers 上で動作する。指標は外部 API から自動取得し、Cloudflare KV に保存する。

## システムの立ち位置と運用フロー
景気玉は、お年玉を渡す側が、渡す相手の前でスマホから開いて使う画面です。お年玉の金額そのものや渡す相手の情報は管理しません。

| 場面 | 誰が | やること |
| --- | --- | --- |
| 日々 (自動) | システム (Cron) | 外部 API から 6 指標を取得して ○/× を判定し、結果を KV に保存する。履歴も追記する |
| お年玉を渡すとき | 渡す側・もらう側 | 渡す側がスマホで `/` を開く。もらう側がルーレットを回し、出た上乗せ額を、渡す側が自分で決めた基準額に足して渡す |
| 振り返り | 誰でも | `/history` で過去の指標と当たり枠数を見る |
| 判定に誤りがあったとき | 開発者 | Cron を待たず、取得・判定の処理を手動で再実行する。管理画面は設けない |

## 用語
| 用語 | 意味 |
| --- | --- |
| 指標 | 景気の判定に使う経済指標。全 6 種類。それぞれ「○」(景気が良い) か「×」で判定する |
| 当たり枠 | ルーレット 10 マスのうち、上乗せが発生するマス |
| 大当たり | 当たり枠が 4 以上のときに 1 マスだけ現れる、上乗せ額が大きい当たり |
| 上乗せ額 | ルーレットの結果として基準額に足す金額 |
